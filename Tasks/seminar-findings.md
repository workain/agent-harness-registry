# Seminar 4 findings — moved out of this repository

The 969-line findings list that used to be here was written for the author of the Seminar 4
branch, in Russian, and its method was quoting Russian-language slides verbatim. This
repository is English-only (root `CLAUDE.md`, LANGUAGE), and translating a document whose
value is its verbatim citations would have turned those citations into paraphrase while making
it unreadable to the one person it was addressed to.

It now lives unchanged, byte for byte, in the PMO repository that governs this one —
`workain/agent-lab-manager`, at `Tasks/20260924_registry_english_rework/seminar-findings.md`,
where Russian operator-facing artifacts are allowed. That repository's log in the same
directory records why.

The original bytes remain in this repository's history: `git show 7f0d879:Tasks/seminar-findings.md`.

This stub is deliberately not deleted. A file that simply vanished from `main` would be
indistinguishable from one nobody ever wrote.
