# Devin

**Registry entry:** `data/engines/devin.yaml`

## What it is

Cognition's AI-software-engineer product family: Devin Cloud (the original autonomous web-based
agent, tool-using with a persistent Cognition-managed workspace — terminal, code editor, browser),
Devin Desktop (a local IDE — **as of 2026-06-02 this is the rebranded Windsurf**, not a separate
later release; see this registry's `windsurf` entry, now superseded by this one), Devin CLI, Devin
Review (PR/visual QA), and Devin Windows VM. Sessions start from Slack/Teams (tag Devin in a
thread), Linear (assign a ticket), the web app, the CLI's `/handoff`, or the API. Devin Desktop
positions itself as "the home for every agent you run" — an Agent Command Center managing local
and cloud agents via the Agent Client Protocol (ACP), including third-party agents (Codex, Claude
Agent, OpenCode) alongside Cognition's own SWE-1.6, with "Spaces" grouping related sessions/PRs/
files. Devin Local (claimed "30% more token efficient") replaced Cascade as Desktop's primary
local agent in the rebrand.
