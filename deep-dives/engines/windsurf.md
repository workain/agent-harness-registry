# Windsurf (Cascade) — renamed Devin Desktop

**Registry entry:** `data/engines/windsurf.yaml`

## What it is

**SUPERSEDED, not discontinued.** As of 2026-06-02, Cognition rebranded Windsurf as "Devin
Desktop" — see this registry's `devin` entry for the current, actively-maintained product.
Confirmed this cycle by fetching https://windsurf.com directly and receiving a 308 Permanent
Redirect to https://devin.ai/desktop, plus Cognition's own announcement blog post. Per that
announcement: "Devin Desktop is a new look for the product you already love" — existing
Windsurf users' plans, pricing, extensions, and settings carried over unchanged. Devin Local
now replaces Cascade as the primary local agent ("30% more token efficient" per Cognition).

Historically (pre-rebrand): an AI-native IDE (formerly Codeium) built around the Cascade agent —
multi-file understanding via a proprietary "Fast Context" indexing system (no manual
file-tagging needed), terminal command execution, and cross-session project memory. Acquired by
Cognition (maker of Devin) for ~$250M in December 2025; Windsurf 2.0 (April 2026) embedded
Devin's autonomous agent directly into the IDE ahead of the full rebrand two months later.
