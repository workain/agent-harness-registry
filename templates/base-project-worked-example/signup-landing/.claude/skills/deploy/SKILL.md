# deploy — публикация signup-landing на прод

Процедура целиком, одним шагом, без вариантов. Свобода здесь низкая намеренно: операция
хрупкая, ошибка видна снаружи, и «немного по-другому на каждом прогоне» — ровно то, чего
здесь быть не должно.

## 0. Предполётная проверка — одна команда, и она обязательна

```bash
npm run build && if grep -q 'REPLACE_WITH_YOUR_FORM_ID' dist/index.html; then
  echo 'STOP: форма всё ещё указывает на заглушку endpoint — не публиковать'; exit 1
fi
```

Именно `if`, а не `&& echo … && exit 1`: цепочка через `&&` возвращает `1` и когда заглушка
найдена, и когда её нет (последним в цепочке оказывается неуспешный `grep`), то есть шаг 0
никогда не пропускает дальше. Проверено прогоном на подставленном endpoint — см. «Проверку»
ступени 4 в README сборки.

`action` формы в `index.html` — заглушка `REPLACE_WITH_YOUR_FORM_ID` (`CLAUDE.md`, раздел
`Project-specific conventions`). Она переживает сборку без единого предупреждения: `vite` не
знает, что эта строка — заглушка, а не адрес. Выложенная с ней страница выглядит полностью
рабочей и молча теряет **каждую** заявку. Проверяется именно `dist/index.html`, а не
`index.html`: публикуется собранное.

Сработала проверка — подставить свой endpoint и начать заново с шага 0, не «продолжить со
шага 1».

## 1. Шаг

```bash
npm run build && wrangler pages deploy dist
```

Требуется: аккаунт Cloudflare и авторизованный `wrangler` (`wrangler login` один раз на
машину, либо `CLOUDFLARE_API_TOKEN` в окружении — **не** в репозитории).

## 2. Проверить вывод на URL продакшена

`wrangler` печатает URL развёртывания. Открыть **его**, не `localhost`, и проверить три вещи:

1. страница отдаётся (не 404 и не прошлая версия — сверить с только что собранным `dist/`);
2. форма на месте, поля `name` и `email` присутствуют;
3. отправка с пустыми полями блокируется, с заполненными — уходит на ваш endpoint (тот
   самый, который подставлен вместо заглушки).

Пункт 3 — единственное, что отличает «файлы выложены» от «форма работает». Тесты его не
покрывают: `tests/form.spec.ts` перехватывает запрос через `page.route` и в интернет не ходит.

## Узкая область

Этот скилл публикует **уже готовое** содержимое `dist/`. Он не правит страницу, не
подставляет endpoint формы за вас (шаг 0 только не даёт выложить заглушку), не запускает
тесты и не откатывает предыдущее развёртывание. Правка кода, `npm run dev` и
`npx playwright test` — обычная работа сессии, не этот скилл.

## Почему `disable-model-invocation: true`

`CLAUDE.md` этого проекта говорит: *«Никогда не запускать деплой на прод без явного
запроса»*. Записанное правило агент может и выполнить, и проигнорировать — что разобрано
ступенью 1 этой сборки на живом случае. `disable-model-invocation: true` — не просьба:
Claude Code не даёт модели загрузить этот скилл самостоятельно и, если она попробует
обойти его и повторить шаги деплоя другим путём, блокирует вызов и прямо указывает ей
этого не делать (официальная справка,
`code.claude.com/docs/en/skills`, § «Control who invokes a skill», загружено 2026-09-20; там
же `/deploy` назван примером ровно для этого поля: *«You don't want Claude deciding to deploy
because your code looks ready»*).

Цена честная и её надо знать: с этим полем `description` **не грузится в контекст вообще**
(та же справка, таблица в том же разделе) — значит, автовыбор по смыслу запроса выключен, и
скилл достижим только явным `/deploy`. Для деплоя это выигрыш, а не потеря. Для
скилла-знания (`/verify`, справочник по формату) поле было бы ошибкой: там автовыбор и есть
вся польза.

## Сноска: почему `description` написан так, а не «Helps with deployment»

Из-за поля выше модель этот `description` не увидит — но `/skills` и человек, который через
полгода будет искать, чем публиковался сайт, увидят. Поэтому он написан как запрос, который
этот человек набрал бы в поиск: конкретные команды, конкретные слова-триггеры («выложи на
прод», «задеплой»), и явное «не для этого». Расплывчатые `«Helps with documents»`,
`«Processes data»` официальная справка по авторству скиллов называет прямыми антипаттернами —
скилл с таким описанием не находится ни моделью, ни человеком.
