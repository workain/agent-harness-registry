# Правила для тестов

Второй адрес из трёх. Фронтматтер `paths:` выше — не украшение: правило подгружается
**только когда агент открывает файл, попавший под этот glob**. В сессии, которая тестов не
касается, оно не стоит ни одного токена.

- Тесты не ходят в интернет. Внешние вызовы перехватываются <чем>; новый тест,
  делающий такой вызов, обязан делать то же.
- Тест, который «иногда падает», чинится или удаляется, но не перезапускается.
