Не пересказ кода — код агент прочитает сам. Эта строка ориентирует.

## Ворота

Одно правило, которое агенту нельзя нарушать самому. Начните ровно с одного — того,
цена нарушения которого для вас реальна. Примеры формулировок, выберите своё:

- Никогда не запускать деплой на прод без явного запроса.
- Никогда не трогать `payments/`.
- Никогда не мержить свой собственный PR.

## Где что лежит

Указатели, не содержание. Каждая строка — один адрес и одна фраза «что там».

- «Готово» для этого проекта: `spec.md`.
- Почему принято решение: `DECISIONS.md`; с последствиями надолго — `doc/adr/`.
- Правила, действующие только на тесты: `tests/CLAUDE.md` — прочитать перед правкой в `tests/`.
- Текущая задача, что уже проверено: `.tasks/active/`.
- Ворота и доказательство, что они срабатывают: `.claude/settings.json`,
  `.claude/hooks/selftest-branch-guard.sh`.
