# Правила для тестов

Второй адрес из трёх: правило, которое действует только на `tests/`, лежит рядом с
`tests/` — а не в корневом `CLAUDE.md`, где его читают все и всегда.

- Тесты не ходят в интернет. Внешние вызовы перехватываются <чем>; новый тест,
  делающий такой вызов, обязан делать то же.
- Тест, который «иногда падает», чинится или удаляется, но не перезапускается.
